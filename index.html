See what fills your drive and what's safe to clean

Disk Heatmap scans a Windows drive and draws it as a heat map. Every folder and file is a rectangle sized by the space it takes, with folders drawn inside folders. Then it tells you, in plain English, which caches are safe to delete.

Download for Windows Disk-Heatmap-Setup-x64.exe How it works

Free. Windows 10 and 11, x64. The installer isn't code-signed yet, so Windows asks once: here's what to click.

  1. Scan

    Pick a drive. Disk Heatmap walks every folder and shows its count as it goes.

  2. Map

    Folders draw inside folders, tinted by kind and deeper as they get bigger.

  3. Zoom

    Click a folder to zoom in. Back and Forward work like your browser.

  4. Clean

    Known caches come with a verdict. Clean empties a safe one after you confirm.

Big things look big

A scan turns the whole drive into one picture. Each rectangle's area is its size on disk, so the folder taking your space is the first thing you see.

It knows what these folders are

Disk Heatmap recognizes the caches and system files below. When it finds one on your drive, it says what it is, whether removing it is safe, and how to free the space. Every rule in detail.

Safe to clean9 rules · Clean button

  • Your temporary files (%TEMP%)Windows

    Scratch files programs leave behind. Files currently in use are skipped automatically.

  • npm package cacheNode.js / npm

    Copies of every package npm has downloaded. npm re-downloads what it needs on the next install.

  • NVIDIA shader cache (DXCache / GLCache)NVIDIA graphics driver

    Compiled shaders the driver saves so games load faster. It is rebuilt automatically; the first launch of each game afterwards may stutter briefly.

  • NVIDIA App downloaded updatesNVIDIA App

    Installer packages the NVIDIA App already downloaded and applied. Old ones are not needed once the update is installed.

  • Recycle BinWindows

    Files you already deleted. They still take space until the bin is emptied.

  • Application crash dumpsWindows

    Memory snapshots saved when programs crashed. Only useful if you are sending them to a developer.

  • VS Code cached extension installersVisual Studio Code

    Old extension installers and web caches VS Code keeps around. Your installed extensions and settings are not here.

  • Ubisoft Connect patch & cache filesUbisoft Connect

    Downloaded launcher/game patches and cached data that have already been applied. Your installed games and saves live elsewhere.

  • Logitech G HUB update cacheLogitech G HUB

    Downloaded firmware and update packages G HUB has already installed. Your device profiles are stored separately.

Your calladvice only

  • Chrome on-device AI modelGoogle Chrome

    A local AI model (Gemini Nano) Chrome downloads for features like “Help me write”. Deleting it alone doesn't help: Chrome downloads it again. Turn the feature off in chrome://flags first.

Managed by Windowsadvice only

  • Page filepagefile.sys / swapfile.sys

    Virtual memory Windows uses when RAM is full. Removing it can cause crashes, so leave it.

  • Hibernation filehiberfil.sys

    If you never hibernate, powercfg /h off in an administrator Terminal removes it, and also turns off Fast Startup.

  • Windows component storeWinSxS

    Deleting files here breaks Windows. DISM /Online /Cleanup-Image /StartComponentCleanup trims it safely.

Nothing goes until you've seen what goes

  • Clean only appears on safe rules. Your call and Managed by Windows items explain how to free the space yourself instead.
  • It always asks first, right in the list, with the size and the number of files.
  • It empties the folder and keeps it. Files that are in use are skipped.
  • It checks the path again before deleting. The app works out each cache's location itself, so nothing on screen can point a delete somewhere else.
  • The Recycle Bin can be emptied too, with a reminder that it can't be restored afterwards.

Your files stay on your PC

Scanning happens entirely on your computer. There's no account and no telemetry. The one thing Disk Heatmap asks the internet is whether a new version is out.

Privacy in detail

It keeps itself current

When it starts, Disk Heatmap checks GitHub for a new version, downloads it in the background and verifies its signature. An Update to X.Y.Z button then appears in the header. Click it to install and restart.

Questions

Is it free?

Yes. Disk Heatmap is free to download and use, and its source is on GitHub.

Will it delete anything on its own?

No. It deletes only when you click Clean on a Safe to clean item and then confirm. Everything else on screen is advice.

Why does Windows warn me about the installer?

The installer isn't code-signed yet. In the “Windows protected your PC” window, click More info, then Run anyway.

Why don't the sizes match what Explorer says?

Disk Heatmap adds up logical file sizes. Hard-linked files, which make up much of WinSxS, are counted each time they appear, so that folder looks bigger than the space it really uses. OneDrive files that live only in the cloud count as 0 bytes, and symlinks and junctions are skipped.

It says some folders were unreadable. What's missing?

Folders that need administrator rights are skipped, and the count appears above the map. Run Disk Heatmap as administrator to include them.

Does it work on a Mac or Linux?

No. Disk Heatmap is a Windows app, for Windows 10 and 11 on x64.

Does it send anything about my files?

No. The scan never leaves your PC. The only network request is the update check to GitHub. Privacy has the details.
