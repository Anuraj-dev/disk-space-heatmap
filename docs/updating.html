Updating

Disk Heatmap keeps itself up to date. A new version downloads quietly in the background and waits until you choose to install it.

On this page

  1. How it works
  2. Installing an update
  3. Updating by hand
  4. If an update doesn't start

How it works

  1. Each time Disk Heatmap starts, it asks GitHub whether a newer version has been released.
  2. If there is one, it downloads the installer in the background while you keep working.
  3. It checks the installer's signature against a key built into the app. An installer that doesn't match is never offered.
  4. An Update to X.Y.Z button appears in the header.

If you're offline, or the check fails for any other reason, nothing is shown and the app works as usual. It checks again the next time you open it.

Installing an update

Click Update to X.Y.Z. Disk Heatmap closes, the installer runs with a small progress window, and the new version opens. The button is unavailable while a scan is running.

You don't have to update straight away. The button stays until you click it or close the app.

Updating by hand

Download the newest installer and run it over your current version:

Download the latest Disk Heatmap

Older versions and release notes are on the releases page. The installer isn't code-signed yet, so Windows may show the SmartScreen prompt again; see Getting started.

If an update doesn't start

If the installer can't start, Disk Heatmap says The update couldn't start. Try again, or restart Disk Heatmap. The downloaded update is kept, so the button stays and you can try again. If it keeps failing, update by hand.
