Getting started

Disk Heatmap installs like any other Windows app. Because the installer isn't code-signed yet, Windows asks you to confirm once.

On this page

  2. Download

  4. Install

Requirements

  • Windows 10 or Windows 11 on an x64 PC.
  • Microsoft Edge WebView2, which Windows 11 already has. If your PC doesn't, the installer downloads it for you, so stay online while installing.

Download

Get the installer, Disk-Heatmap-Setup-x64.exe:

Download Disk Heatmap for Windows

That link always points to the newest version. Every version, with its release notes, is on the releases page.

Windows protected your PC

When you open the installer, Microsoft Defender SmartScreen shows a blue window titled “Windows protected your PC”. It appears because the installer isn't code-signed yet, so Windows doesn't recognize the publisher. That's expected for an unsigned app.

  1. Click More info, the underlined link under the message.
  2. Check that the app name reads Disk-Heatmap-Setup-x64.exe.
  3. Click Run anyway.
Only download from these two places

The download button on this site and the GitHub releases page are the same file. If you got the installer anywhere else, don't run it.

Install

  1. Follow the installer. It asks where to install and then copies the app.
  2. If WebView2 is missing, the installer fetches it during setup.
  3. Open Disk Heatmap from the Start menu.

Your first scan

  1. On Choose a drive to map, click a drive. Each one shows its free space.
  2. The scan counts up as it walks the drive: bytes found, files, folders and time. A full system drive usually takes from a few seconds to a few minutes, depending on how many files it holds.
  3. If you don't want to wait, Stop and show results so far draws the map from what has been counted.
  4. The map appears. Point at any rectangle to see what it is in the side panel; click a folder to zoom in. Reading the map explains the rest.

Running as administrator

Some folders, mostly inside Windows and ProgramData, can't be read without administrator rights. Disk Heatmap skips them and shows how many it skipped above the map, for example 3 folders unreadable. To include them, right-click Disk Heatmap in the Start menu and choose Run as administrator.

A few cleanup rules, such as the NVIDIA App and Logitech G HUB caches, can also need administrator rights to clean.

Uninstalling

Remove it like any other app: Settings > Apps > Installed apps, find Disk Heatmap, and choose Uninstall.
