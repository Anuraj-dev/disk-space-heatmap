Disk Heatmap docs

Disk Heatmap is a free Windows app that draws a drive as a nested heat map and explains which caches are safe to clean. These pages cover everything it does.

Getting startedDownload, get past the SmartScreen prompt, and run your first scan. Reading the mapWhat size, tint, depth and hatching mean, and how to move around. Cleanup rulesEvery cache Disk Heatmap knows, its verdict, and what Clean does. TroubleshootingSizes that don't match Explorer, unreadable folders, skipped files.

At a glance

  • Runs on Windows 10 and 11, x64.
  • Costs nothing. The source is on GitHub.
  • Scans locally. The only network request is the check for a new version. See Privacy.
  • Deletes only when you ask: Clean appears on Safe to clean items and always asks first.
  • Updates itself: a new version downloads in the background and waits for your click. See Updating.
