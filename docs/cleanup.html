Cleanup rules

Disk Heatmap recognizes a short list of caches and system files. For each one it finds, it explains what it is, gives a verdict, and says how to free the space.

On this page

  1. Verdicts
  2. What Clean does
  3. The Recycle Bin
  4. All rules

Verdicts

  • Safe to clean: the files are rebuilt or re-downloaded when needed, or are leftovers nobody uses. These get a Clean button, and their tiles on the map are densely hatched.
  • Your call: removing it is possible but has a trade-off, or needs a step first. Advice only; sparsely hatched on the map.
  • Managed by Windows: Windows needs it. The panel tells you the supported way to shrink it, if there is one. Advice only; this group starts collapsed.

The list only shows rules that match something on the drive you scanned, largest first.

What Clean does

  1. Open an item in the list and click Clean.
  2. The item asks you to confirm, with the size and the number of files: Permanently delete 5.30 GB (48,213 files)? The folder stays; files in use are skipped.
  3. Click Clean again to delete, or Cancel.
  • The folder itself stays; only what's inside is deleted. Programs that expect the folder keep working.
  • Files in use are skipped. The result tells you how much was freed and how many items were skipped, for example Freed 5.30 GB. 12 in-use items were skipped. Close the program that uses them and clean again to get the rest.
  • Deleted files don't go to the Recycle Bin. They're gone, which is why Clean only appears on items that are safe to lose.
  • The app checks the path again before deleting. It works out each cache's location itself from the rule, so nothing on screen can point a delete anywhere else.
  • Links inside the folder (symlinks and junctions) are removed as links; what they point to is not touched.

The free space under Disk and the list update straight away. The map redraws on the next Rescan.

The Recycle Bin

The Recycle Bin of the scanned drive appears as a Safe to clean item with an Empty bin button. It asks first: Empty the Recycle Bin? 6.70 GB can't be restored afterwards. Check nothing in it is still needed.

All rules

Paths use Windows environment variables: %LOCALAPPDATA% is C:\Users\you\AppData\Local, %APPDATA% is …\AppData\Roaming, %PROGRAMDATA% is C:\ProgramData, and {DRIVE} is the drive you scanned. A * matches any one folder name.

NVIDIA shader cache (DXCache / GLCache)

NVIDIA graphics driverSafe to clean

What it is
Compiled shaders the driver saves so games load faster. It is rebuilt automatically; the first launch of each game afterwards may stutter briefly.
How to free it
Delete the folder contents here, or turn on 'Shader Cache Size' limits in the NVIDIA Control Panel.
In the app
Clean empties the folder and keeps it.
Where it looks
  • %LOCALAPPDATA%\NVIDIA\DXCache
  • %LOCALAPPDATA%\NVIDIA\GLCache

NVIDIA App downloaded updates (ota-artifacts)

NVIDIA AppSafe to clean

What it is
Installer packages the NVIDIA App already downloaded and applied. Old ones are not needed once the update is installed.
How to free it
Delete the contents. Needs the app to be run as administrator if access is denied.
In the app
Clean empties the folder and keeps it.
Where it looks
  • %PROGRAMDATA%\NVIDIA Corporation\NVIDIA App\UpdateFramework\ota-artifacts
  • %PROGRAMDATA%\NVIDIA Corporation\*\ota-artifacts

Application crash dumps

WindowsSafe to clean

What it is
Memory snapshots saved when programs crashed. Only useful if you are sending them to a developer.
How to free it
Delete the contents.
In the app
Clean empties the folder and keeps it.
Where it looks
  • %LOCALAPPDATA%\CrashDumps

Your temporary files (%TEMP%)

WindowsSafe to clean

What it is
Scratch files programs leave behind. Files currently in use are skipped automatically.
How to free it
Delete the contents, or use Settings > System > Storage > Temporary files.
In the app
Clean empties the folder and keeps it.
Where it looks
  • %TEMP%

npm package cache

Node.js / npmSafe to clean

What it is
Copies of every package npm has downloaded. npm re-downloads what it needs on the next install.
How to free it
Delete the contents, or run: npm cache clean --force
In the app
Clean empties the folder and keeps it.
Where it looks
  • %LOCALAPPDATA%\npm-cache

VS Code cached extension installers

Visual Studio CodeSafe to clean

What it is
Old extension installers and web caches VS Code keeps around. Your installed extensions and settings are not here.
How to free it
Close VS Code, then delete the contents.
In the app
Clean empties the folder and keeps it.
Where it looks
  • %APPDATA%\Code\CachedExtensionVSIXs
  • %APPDATA%\Code\Cache
  • %APPDATA%\Code\CachedData

Recycle Bin

WindowsSafe to clean

What it is
Files you already deleted. They still take space until the bin is emptied.
How to free it
Empty the Recycle Bin (check nothing in it is still needed).
In the app
Empty bin empties this drive's Recycle Bin.
Where it looks
  • {DRIVE}\$Recycle.Bin

Ubisoft Connect patch & cache files

Ubisoft ConnectSafe to clean

What it is
Downloaded launcher/game patches and cached data that have already been applied. Your installed games and saves live elsewhere.
How to free it
Quit Ubisoft Connect, then delete the contents. May need administrator rights.
In the app
Clean empties the folder and keeps it.
Where it looks
  • %PROGRAMFILES(X86)%\Ubisoft\Ubisoft Game Launcher\cache
  • %PROGRAMFILES(X86)%\Ubisoft\Ubisoft Game Launcher\patch

Logitech G HUB update cache

Logitech G HUBSafe to clean

What it is
Downloaded firmware and update packages G HUB has already installed. Your device profiles are stored separately.
How to free it
Quit G HUB from the tray, then delete the contents. May need administrator rights.
In the app
Clean empties the folder and keeps it.
Where it looks
  • %PROGRAMDATA%\LGHUB\cache
  • %LOCALAPPDATA%\LGHUB\cache

Chrome on-device AI model (OptGuideOnDeviceModel)

Google ChromeYour call

What it is
A local AI model (Gemini Nano) Chrome downloads for features like 'Help me write'. Deleting it alone doesn't help: Chrome downloads it again.
How to free it
In Chrome open chrome://flags, set 'Enables optimization guide on device' to Disabled, restart Chrome, then delete this folder.
In the app
None. Advice only.
Where it looks
  • %LOCALAPPDATA%\Google\Chrome\User Data\OptGuideOnDeviceModel

Hibernation file (hiberfil.sys)

WindowsManaged by Windows

What it is
Holds your memory contents for hibernate and Fast Startup. Windows manages it; never delete it directly.
How to free it
If you never hibernate: open Terminal as administrator and run powercfg /h off (this also disables Fast Startup).
In the app
None. Advice only.
Where it looks
  • {DRIVE}\hiberfil.sys

Page file (pagefile.sys / swapfile.sys)

WindowsManaged by Windows

What it is
Virtual memory Windows uses when RAM is full. Removing it can cause crashes.
How to free it
Leave it. If you must, change its size in System Properties > Advanced > Performance > Virtual memory.
In the app
None. Advice only.
Where it looks
  • {DRIVE}\pagefile.sys
  • {DRIVE}\swapfile.sys

Windows component store (WinSxS)

WindowsManaged by Windows

What it is
System components and update backups. Many files are hard links shared with C:\Windows, so the real size is smaller than shown. Deleting files here breaks Windows.
How to free it
Open Terminal as administrator and run DISM /Online /Cleanup-Image /StartComponentCleanup
In the app
None. Advice only.
Where it looks
  • {DRIVE}\Windows\WinSxS
Missing a cache?

If you'd like Disk Heatmap to recognize another folder, open an issue on GitHub with the app it belongs to and its path.
