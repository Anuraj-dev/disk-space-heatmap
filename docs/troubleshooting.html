Troubleshooting

Answers to the questions that come up most. If yours isn't here, open an issue on GitHub.

Windows won't run the installer

If you see “Windows protected your PC”, click More info, then Run anyway. The installer isn't code-signed yet, so SmartScreen doesn't recognize it. Details are in Getting started.

The installer needs the internet

Disk Heatmap uses Microsoft Edge WebView2. If your PC doesn't have it, the installer downloads it during setup, so connect to the internet and run the installer again.

It says some folders were unreadable

Folders that need administrator rights are skipped, and the count appears above the map. To include them, close Disk Heatmap, right-click it in the Start menu, choose Run as administrator, and scan again.

Sizes don't match what Explorer says

  • Hard links count each time they appear. Disk Heatmap adds up each file's logical size. Much of C:\Windows\WinSxS is hard links to files elsewhere in C:\Windows, so it looks bigger than the space it really uses.
  • Sizes are logical, not on-disk. Compressed files and the slack at the end of each disk cluster mean Explorer's “Size on disk” can differ.
  • OneDrive files that are only in the cloud count as 0 bytes, since they take no space on this PC.
  • Folders that couldn't be read aren't counted; see above.

A folder seems missing

  • It's under 100 MB. Small files and folders are folded into the grey N small items tile of their folder.
  • It's a symlink or junction. These are skipped so nothing is counted twice; the folder they point to is counted where it really lives.
  • It's too deep. Raise the depth with ], or click the parent folder to zoom in.

Clean skipped some files

Files that are open in another program can't be deleted, so Clean skips them and reports how many, for example 12 in-use items were skipped. Close the program that uses the cache (VS Code, a game launcher, a browser) and clean again. Temporary files in use by Windows itself may stay until you restart.

Clean says access is denied

Some caches under C:\ProgramData or C:\Program Files (x86) belong to services that run with more rights. Quit the app the cache belongs to, then run Disk Heatmap as administrator and clean again.

The map didn't change after cleaning

That's expected. The cleanup list and free space update straight away, but the map shows the last scan. Click Rescan to redraw it; you'll come back to the folder you were in.

Report a problem

Open an issue on GitHub. Say which Windows version you're on, what you clicked, and what you saw. A screenshot helps; blur any folder names you'd rather not share.
